### Задание 2 **(1)**

*Функция* **dswap** *должна была обменивать значения своих параметров.* 
*(На выводе должно было получиться* ```3.4 1.5```.)
*В чем ошибка при написании этой функции? Как ее исправить? 
Что передавалось в параметры у исходной функции и у исправленной?* 
```
#include <iostream>
void dswap(double x, double y) {
   double t = x;
   x = y;
   y = t;
}
int main(void) {
   double x = 1.5, y = 3.4;
   dswap(x, y);
   std::cout << x << " " << y << std::endl;
   return 0;
}
```
#### Ответ:
Ошибка в том, что функция меняет местами только локальные копии переменных, которые удаляются после ее завершения, а оригинальные переменные в main не меняются.
```cpp
#include <iostream>
void dswap(double& x, double& y) { 
    double t = x;
    x = y;
    y = t;
}

int main(void) {
    double x = 1.5, y = 3.4;
    dswap(x, y);
    std::cout << x << " " << y << std::endl;
    return 0;
}

```
В исходной программе передавались копии значений `1.5` и `3.4`, а в исправленной - ссылки на сами оригинальные переменные `x` и `y` из `main`.

### Задание 8 **(3)**

*Объясните работу приведенной ниже программы.
Какие ошибки в ней имеются? (Виды ошибок смотрите в лекции.)*
```
#include <iostream>
int main() {
    int *p = new int [10];
    int *q = new int [10];
    for (int i = 0; i <= 10; i++)
        p[i] = i;
    q = p;
    delete[] p;
    for (int i = 0; i <= 10; i++)
        std::cout << q[i] <<" ";
    delete[] q;
    return 0;
}
```
#### Ответ:

- Выход за границы массива: Эта ошибка встречается в обоих циклах for (int i = 0; i <= 10; i++).
Массив из `10` элементов имеет индексы от `0` до `9`. На последней итерации `(i = 10)` происходит обращение к `p[10]` и `q[10]`, то есть запись и чтение в чужую область памяти.
- Утечка памяти: Эта ошибка встречается в строке q = p;. Перезаписывая адрес в указателе `q`, программа теряет единственную ссылку на второй массив `(new int[10])`, который был выделен изначально. Освободить эту память до конца работы программы становится невозможно.
- Использование висячего указателя: Эта ошибка встречается в выводе `std::cout << q[i]` после вызова `delete[] p;`. После освобождения памяти через `p` указатель `q` продолжает хранить ее адрес, но сама память больше не принадлежит программе. Чтение из нее вызывает неопределенное поведение.
- Двойное освобождение памяти: Эта ошибка встречается в строкe `delete[] q;`. Т.к. `p` и `q` указывают на один и тот же адрес, вызов `delete[] q` пытается повторно удалить память, уже освобожденную строкой `delete[] p;`.
