### Задание 1 **(2)**
*Оцените работу следующих фрагментов программ. Какие из них обладают неоднозначным поведением? Почему?*
```
int x=10, y=3;
std::cout << std::min(x=15, x+y);
```
```
int x=10, y=3;
x=15, y+=x, x+=y;
```
```
int x=10, y=9;
if (x>y++ && y++>9)
  cout << "yes" << endl;
cout << y;
```

*Тексты программ разместите в папке с номером задания*

#### Ответ:

**Программа 1:**
*Порядок вычисления аргументов функции не определен стандартом C++. Может быть вычислено сначала x=15, затем x+y (где x уже 15).*

**Программа 2:**
*Оператор запятой гарантирует последовательное выполнение слева направо.*
- x=10 -> x=15
- y+=x -> y=3+15=18
- x+=y -> x=15+18=33

*Неоднозначности нет.*

**Программа 3:**

- x>y++ -> 10>9, y становится 10
- y++>9 -> 10>9, y становится 11
- Выводится "yes", затем y=11

*Нет неоднозначности, так как && гарантирует порядок вычисления.*

### Задание 2 **(2)**
*Как записать следующие строки программы на С++ в виде одного
выражения? Приведите несколько способов, в том числе с использованием операторов инкремента.*
*Проверьте работу написанных программ*
```
x=x+1;
z=z+2*x+3*y;
y=y+1;
```
#### Ответ:
**Способ 1** Через запятую:
```
x+=1, z = z + 2*x + 3*y, y+=1;
```
**Способ 2** С инкрементами:
```
x++, z += 2 * x + 3 * y, y++;
```
В обоих вариантах сначала увеличивается `x`, затем `z` пересчитывается с учетом уже увеличенного `x` и изначального `y`, после чего увеличивается `y`.

std::vector<int> x(10);
for (...)

### Задание 4 **(2)**

*Почему присваивание* ```(++x)=y``` *является синтаксически правильным, а*
```(x++)=y``` - *нет? Запишите текст сообщения об ошибке, переведите и объясните его.*

#### Ответ:

- `++x` возвращает lvalue (ссылку на сам объект x), поэтому ему можно присвоить значение.
- `x++` возвращает rvalue (временную копию старого значения), которому нельзя присвоить значение.

**Сообщение об ошибке:**
```
C:/Users/Кирилл/CLionProjects/111/main.cpp:4:7: error: lvalue required as left operand of assignment
    4 |     (x++) = y;
      |     ~~^~~
```
Перевод: `Требуется lvalue в качестве левого операнда присваивания`
Присваивание требует модифицируемый объект (lvalue), а постфиксный инкремент создает временное значение.

### Задание 5 **(2)**

*Программисты на Python для обмена значений двух переменных часто пишут строку*
```
a,b = b,a
```
*Проверьте, будет ли аналогичная строка на С++ (с точкой с запятой в конце) являться синтаксически
правильной? Будет ли она обменивать значения переменных? Как в языке С++ вычисляется это выражение?*

#### Ответ:
*Такая строка в `c++` будет синтаксически верной, но не будет обменивать значения переменных, потому что jператор запятой имеет низкий приоритет, следовательно выражение интерпретируется как: `a, (b = b), a;`*
- Сначала вычисляется a (ничего не делает)
- Затем b = b (присваивание самому себе)
- Затем a (ничего не делает)

В с++ это можно сделать при помощи `std::swap(a, b);`

### Задание 6 **(2)**

*Проверьте работу следующего фрагмента программы*
```
  std::string s;
  for (int i=0; i<1000000; i++)
     s += 'a';
  std::cout << s.size();
```
*Измените третью строку на*
```
s=s+'a';
```
*Изменится ли что-нибудь в ее работе? Объясните результат.*

 #### Ответ:
*Оба варианта в итоге создают строку из миллиона символов 'a', поэтому s.size() выводит 1000000, но `s += 'a'` гораздо эффективнее, т.к. `s += 'a'` дописывает символ к существующей строке, a `s = s + 'a'` создаёт новую строку, копирует в неё прежнее содержимое и затем присваивает результат обратно. При повторении миллион раз это может привести к гораздо более долгой работе.*
